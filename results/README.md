# Results

## Overview

This directory contains the training outputs, evaluation metrics, and performance visualizations for all object detection models trained as part of this project.

The purpose of this folder is to provide a centralized location for comparing the performance of different detection models before selecting the final ensemble architecture.

---

# Folder Structure

This directory currently contains **three folders**, each corresponding to a specific model.

```text
Results/
│
├── YOLO11m/
├── YOLO26m/
└── RT-DETR/
```

Each folder contains the complete training outputs generated by Ultralytics for that particular model.

---

# Important Files

Each model directory contains several files generated during training. The most important ones for analysis are:

## 1. `results.csv` ⭐

This is the primary file for quantitative analysis.

It contains training and validation metrics recorded after every epoch, including:

- Training losses
- Validation losses
- Precision
- Recall
- mAP@50
- mAP@50-95
- Learning rate
- Epoch timing

This file should be used for:

- Performance comparison
- Metric plotting
- Trend analysis
- Identifying convergence
- Detecting overfitting or underfitting

---

## 2. Training Curves ⭐

Each folder contains automatically generated plots that visualize the training process.

Typical plots include:

- Loss curves
- Precision curves
- Recall curves
- mAP curves
- Precision-Recall curves
- F1-score curves
- Confusion Matrix
- Validation visualizations

These figures provide a quick visual understanding of model performance and should be used alongside `results.csv` during evaluation.

---

# Files to Ignore

## `args.yaml`

This file contains the training configuration and hyperparameters used during execution.

For the purpose of performance evaluation and model comparison, **this file can be ignored**.

Training configurations, CLI commands, and hyperparameter explanations are already documented separately in the **`Yolo_Training_CLI`** directory.

---

# Recommended Evaluation Workflow

For each model:

1. Open `results.csv`.
2. Examine the training and validation metrics across all epochs.
3. Review the generated performance curves.
4. Compare the metrics with the other trained models.
5. Record strengths and weaknesses.
6. Use the observations to guide the design of the final ensemble architecture.

# Purpose of this Directory

The contents of this directory will be used to:

- Compare the performance of different detection models.
- Identify the best-performing detector.
- Analyze convergence behaviour.
- Evaluate precision, recall, and localization quality.
- Support the selection of the final ensemble strategy.
- Provide evidence for integrating the Agentic AI decision layer in the subsequent phase of the project.
